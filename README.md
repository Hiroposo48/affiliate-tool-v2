# 📦 アフィリエイトカード生成ツール

Amazon・楽天の商品カードHTMLをかんたんに作成できるローカルツールです。  
WordPressなしで使えるRinker代替ツールとして設計しています。

---

## ✅ できること

- 楽天市場で商品をキーワード検索して選択
- AmazonのURLを貼るだけで商品情報を取得
- 楽天・Amazon両対応のアフィリエイトカードHTMLを生成
- 価格・取得日時を自動記録
- コピーしてブログに貼るだけで完成

## 🖥️ 動作環境

- Mac / Windows
- Node.js v18以上

---

## 📦 インストール手順

### 1. Node.jsをインストール

以下のサイトからLTS版をダウンロードしてインストールしてください。

👉 https://nodejs.org/ja/

### 2. このリポジトリをダウンロード

画面右上の「Code」→「Download ZIP」でダウンロードして解凍してください。

### 3. 起動する

**Macの場合**  
`start_mac.sh` をダブルクリック  
※初回は右クリック→「開く」で実行してください

**Windowsの場合**  
`start_win.bat` をダブルクリック

ブラウザが自動で開きます。

---

## ⚙️ 初期設定

ツールを起動したら「設定」タブを開いて以下を入力して保存してください。

| 項目 | 説明 |
|------|------|
| Amazon アソシエイトID | 例：yourname-22 |
| 楽天アフィリエイトID | 楽天アフィリエイトの管理画面で確認 |
| 楽天アプリID | 下記の手順で取得 |

---

## 🔑 楽天アプリIDの取得方法

1. 楽天デベロッパーにアクセス  
👉 https://webservice.rakuten.co.jp/

2. 楽天アカウントでログイン

3. 右上の「+ New App」をクリック

4. 以下を入力して登録
   - Application Name：任意（例：myblog-tool）
   - Application URL：自分のブログURL

5. 登録後に表示される「Application ID」をコピー

6. ツールの設定タブの「楽天アプリID」に貼り付けて保存

---

## 📝 使い方

1. 「カード生成」タブを開く
2. 商品名を入力して「検索」
3. 候補一覧から商品をクリックして選択
4. 必要であればAmazonで同じ商品を探してURLを貼り付け
5. Amazon価格を手入力（任意）
6. 「カードを生成」ボタンを押す
7. 生成されたHTMLをコピーしてブログに貼り付け
